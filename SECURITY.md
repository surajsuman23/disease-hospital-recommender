# Security

This public demonstration has no user accounts and does not retain prediction records. Never submit real patient records, credentials or confidential information in issue reports.

Report suspected vulnerabilities privately through the maintainer's GitHub contact or private security-reporting mechanism when available. Include the affected commit, reproduction steps using fictional inputs and expected impact. Do not post secrets or exploit payloads against other users.

The request budget is process-local, not a replacement for provider-level abuse controls. The application has not undergone an independent penetration test. See the production-readiness document for open release gates.
